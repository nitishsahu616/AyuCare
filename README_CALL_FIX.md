AyuCare contact button notes

The consultation section now lists the AyuCare team contacts and has:
- Call buttons using tel:+91... links. These open the default phone/calling app when the device has one configured.
- WhatsApp buttons using https://wa.me/91... links. These open a WhatsApp chat; the user can start a voice/video call from WhatsApp if supported.

A web page cannot silently place a regular phone call. On computers, the tel: link only works if a calling app/handler is configured. Live audio/video calls inside the website require a separate calling provider and integration; the old visual tele-chamber is not a real call.
